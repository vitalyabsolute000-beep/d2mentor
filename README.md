# D2Mentor

**Тихий тренер. Без голоса. С цифрами.**

Лёгкий оверлей для Dota 2 на Windows: план сборки с таймингами, следующий предмет и ETA, подсказки без озвучки и без аккаунта. Работает на официальном GSI и данных OpenDota, локально.

## Что уже умеет

- принимает GSI от Dota 2 на `127.0.0.1:38397`, проверяет токен;
- сам ставит и удаляет `gamestate_integration_d2mentor.cfg` в папке игры (Steam ищется через реестр и `libraryfolders.vdf`);
- строит план по герою из OpenDota: `itemPopularity` + `itemTimings` (популярность, медианное время покупки, винрейт);
- считает «следующий предмет», сколько золота не хватает и ETA по GPM;
- засчитывает уже купленные компоненты (Boots + Gloves → прогресс Power Treads);
- показывает весь план: купленное зачёркнуто, следующее подсвечено, у остальных медианный тайминг;
- показывает всё в прозрачном click-through оверлее справа; **F8** — скрыть/показать;
- трей: настройки, оверлей, папка данных, выход;
- кнопка «Тест без Dota» — отправляет фейковый матч в оверлей.

## Чего не делает (принципиально)

- никакой озвучки, TTS и звуковых эффектов;
- никакого чтения памяти игры, инжекта, хуков, автокликеров;
- никаких аккаунтов, облака и телеметрии;
- не показывает скрытую информацию (туман войны и т.п.).

## Требования

- Windows 10/11 x64, WebView2 (в Win11 уже есть);
- Dota 2 в режиме **Borderless Windowed** (в exclusive fullscreen оверлей не виден);
- интернет — только для загрузки билдов OpenDota (кэш 12 ч, офлайн работает на кэше).

## Запуск (dev)

Тулчейн проекта лежит на диске D:

```powershell
$env:RUSTUP_HOME = 'D:\Dev\rust\rustup'
$env:CARGO_HOME  = 'D:\Dev\rust\cargo'
$env:Path       += ';D:\Dev\rust\cargo\bin'
```

```powershell
cd d2mentor
npm install
npm run tauri dev
```

Первая сборка Rust занимает несколько минут. MSVC Build Tools: `D:\Dev\VS\BuildTools`.

## Первый запуск

1. Открыть D2Mentor, нажать **«Установить GSI-конфиг»**.
2. Запустить Dota 2 (конфиг подхватывается при старте игры).
3. Зайти в матч — панель покажет героя, время, золото и следующий предмет.
4. **F8** — скрыть/показать оверлей.

Проверить без игры: кнопка **«Тест без Dota»**.

## Где лежат данные

- токен GSI: `%LOCALAPPDATA%\D2Mentor\gsi-token.txt`
- кэш справочников: `%LOCALAPPDATA%\D2Mentor\meta.json`
- билды героев: `%LOCALAPPDATA%\D2Mentor\builds\<hero_id>.json`
- конфиг Dota: `<Steam>\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration\gamestate_integration_d2mentor.cfg`
