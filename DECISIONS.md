# DECISIONS — D2Mentor

## 2026-11-19

**Стек: Rust + Tauri v2, а не Electron.**
Уже стоял Rust, MSVC и каркас; Tauri даёт меньше RAM/CPU, нативный трей и прозрачное окно.
Electron-вариант из ТЗ отброшен: переписывать готовый бэкенд смысла нет.

**Python — только для CV (этап 4).**
OpenCV/шаблонное сравнение на Python быстрее в разработке. Сайдкар будет общаться по localhost HTTP (порт 38399), ядро продолжит работать без него.

**Порт GSI — 38397, свой конфиг.**
PTS Booster занимает 38396. Отдельный файл `gamestate_integration_d2mentor.cfg` исключает конфликт; токен — 64 hex, хранится в `%LOCALAPPDATA%\D2Mentor\gsi-token.txt`.

**Справочники предметов — из dotaconstants (raw GitHub), не из `/constants/items`.**
Эндпоинт OpenDota отваливался по таймауту (>180 с). `items.json` (≈500 КБ) + `item_ids.json` (≈17 КБ) отдаются мгновенно и версионируются.

**Кэш — файловый JSON на 12 ч, без SQLite в MVP.**
Меньше зависимостей; SQLite добавим на этапе 5 (история матчей).

**Оверлей — отдельное прозрачное окно Tauri, click-through, F8.**
Никакого чтения памяти/инжекта. Хоткей F8 выбран как надёжный (Backquote конфликтует с консолью Dota).

**ИИ — не в MVP.**
Сначала детерминированные правила и цифры OpenDota. OpenRouter добавим, когда правила стабильны.

**Название — D2Mentor.**
Папка проекта — локальная и в репозиторий не попадает; данные — `%LOCALAPPDATA%\D2Mentor`.

## 2026-11-19 (после первого теста в матче)

**Компоненты засчитываются в прогресс предмета.**
GSI не говорит, на какой предмет идёт купленная часть, поэтому берём граф `components` из dotaconstants: прогресс = текущее золото + стоимость уже купленных частей следующего предмета. Иначе покупка Gloves/Boots «сбрасывала» счётчик.

**Время — из `clock_time`, а не `game_time`.**
`clock_time` совпадает с HUD Dota и отрицателен до гудка, так что «-1:30» на пике выглядит как в игре.

**План = тайминги + стадии.**
`itemTimings` иногда содержит 2–3 предмета. План из таймингов дополняется `early/mid/late` (только готовые предметы, cost ≥ 1000), а выборка фильтруется по 3% от максимума, чтобы в план не попадали случайные айтемы с 30 играми.

**Оверлей показывает весь план.**
Список из 8 предметов: купленное зачёркнуто, следующее подсвечено, справа — медианный тайминг. Без этого было непонятно, что делать после Power Treads.
